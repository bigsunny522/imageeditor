# 無料版・有料版 仕様書

最終更新: 2026-10-06
ステータス: ドラフト。「8. 未決事項」が決まったら確定とする

---

## 1. 目的と方針

### 目的
- 撮影情報フレームツールを、買い切りの有料版と広告で収益化する
- 無料版の出力画像が SNS に投稿されることで、集客につなげる

### 方針
- 無料版だけで「SNS に投稿したくなる画像」が完成すること。編集機能は制限しない
- 有料版は、たくさん使う人・本気の人ほど欲しくなる機能で差をつける
- 広告は保存時だけ出す。編集中の画面には出さない
- 処理はこれまでどおりすべてブラウザ内で完結させる。画像をサーバーへ送らない

## 3. 無料版の仕様

### 3.1 書き出し解像度の上限
- 書き出す画像の長辺が 2048px を超える場合、縦横比を保ったまま長辺 2048px に縮小する
- フレームや文字、ロゴも同じ比率で縮小し、見た目のバランスがプレビューと変わらないようにする
- 縮小したときは、保存画面に「有料版なら元の解像度で保存できます」と表示する
- この上限は「保存」と「共有」の両方に適用する

### 3.2 クレジット表示
- 書き出し画像の右下に、小さく「made with ○○」を入れる。ツール名は未決
- フレームがある場合はフレームの余白内に、フレームなしの場合は画像の上に半透明で入れる
- 文字の大きさは画像の短辺の約1.5%を目安にし、写真の邪魔にならない大きさにする
- プレビューにも表示し、書き出し結果と一致させる
- 無料版ではオフにできない

### 3.3 保存時のカウントダウン画面
保存ボタンを押してから画像が保存されるまでの流れ:

1. 保存ボタンを押すと、モーダルを表示する
2. モーダル内に以下を表示する
   - カウントダウン。秒数は未決、5秒を想定
   - Adsterra のバナー広告1枠
   - 有料版の案内。「980円で広告なし・フル解像度・一括処理」と購入ボタン
3. カウントダウンが終わったら「保存する」ボタンを有効にする
4. 「保存する」を押すと画像を保存し、モーダルを閉じる

- 共有ボタンも同じモーダルを通す。共有だけ広告を回避できる状態にしない
- 広告の読み込みに失敗しても、カウントダウン終了後は保存できるようにする

### 3.4 広告の運用ルール
- 使う広告は Adsterra の Native Banner または Display Banner 300×250 の1枠のみ
- ポップアンダー、ダイレクトリンク、ソーシャルバーは使わない
- 広告は保存時のモーダルにだけ出し、編集画面には出さない
- 管理画面で、アダルト・ギャンブルなどのカテゴリを除外する
- 有料版では広告のスクリプト自体を読み込まない

## 4. 有料版の仕様

### 4.1 フル解像度での書き出し
- 元画像の解像度のまま書き出す

### 4.2 書き出し形式と画質
- PNG / JPEG / WebP から選べる
- JPEG と WebP は画質を 60〜100 の範囲で指定できる。初期値は 92
- 選んだ形式と画質はブラウザに保存し、次回も引き継ぐ

### 4.3 広告なし・クレジットなし
- 保存時のモーダルを出さず、すぐ保存する
- クレジットを入れない

### 4.4 一括処理
- 複数の画像をまとめて読み込み、同じフレーム設定で書き出す
- EXIF は画像ごとに読み取って、それぞれのフレームに反映する
- 書き出しは ZIP にまとめてダウンロードする
- 一度に処理できる枚数の上限は 50 枚を想定。端末のメモリ負荷を見て調整する
- 処理中は進み具合を表示し、途中でキャンセルできる

### 4.5 プリセット保存
- フレームのスタイル・配置・色・テキスト・ロゴなどの設定に名前を付けて保存できる
- 保存先はブラウザ内。上限は 20 件を想定
- 呼び出し・名前の変更・削除ができる
- 設定を JSON で書き出し・読み込みでき、別の端末にも移せる

### 4.6 追加のフレームデザイン・フォント
- 有料版限定のフレームデザインとフォントを追加する。数と内容は未決
- 無料版でも選択肢として見せ、選ぶとプレビューはできるが、保存時に有料版の案内を出す

## 5. 購入とライセンス

### 5.1 購入の流れ
1. 購入ボタンを押すと、Stripe Checkout の決済画面に移る
2. 決済が完了すると、ツールの完了ページに戻る
3. Cloudflare Workers が Stripe に決済の完了を確認し、ライセンスキーを発行する
4. ライセンスキーを画面に表示し、購入時のメールアドレスにも送る
5. ブラウザにライセンス情報を保存し、有料版の機能を有効にする

### 5.2 別の端末・ブラウザで使う
- 「ライセンスを入力」画面で、メールアドレスとライセンスキーを入力すると有効になる
- 同時に使える端末数は 3 台を想定

### 5.3 構成
- 決済: Stripe Checkout
- ライセンスの発行と確認: Cloudflare Workers
- ライセンスの保存: Cloudflare KV または D1
- メール送信: Resend などのメール配信サービス

### 5.4 前提として受け入れること
- 処理がすべてブラウザ内なので、技術に詳しい人が有料機能の制限を外すことは防ぎきれない
- 普通の利用者が簡単に回避できない程度の対策にとどめ、開発コストをかけすぎない

## 6. 販売にあたって必要なもの

- 特定商取引法に基づく表記のページ
- 利用規約。返金の条件を含める
- プライバシーポリシーの更新。決済情報とメールアドレスの扱い、広告配信について追記する
- 独自ドメインでの公開。決済と広告の信頼性のため

## 7. 開発の進め方

### フェーズ1: 集客の土台
- タイトル・description・OGP の設定、`lang="ja"` への変更
- アクセス解析の導入
- ツール名とドメインの決定、独自ドメインでの公開

### フェーズ2: 無料版の制限と広告
- 書き出し解像度の上限
- クレジット表示
- 保存時のカウントダウン画面と Adsterra の広告
- 形式と画質の選択 UI。無料版では PNG のみ選べる状態にする

### フェーズ3: 購入とライセンス
- Stripe Checkout と Cloudflare Workers によるライセンス発行
- ライセンスの入力と、有料機能の切り替え
- 特定商取引法の表記、利用規約、プライバシーポリシー

### フェーズ4: 有料機能
- 一括処理
- プリセット保存
- 追加のフレームデザイン・フォント
